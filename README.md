## Sobre mim

Oi, eu sou o Vilker. Estudo Análise e Desenvolvimento de Sistemas e passo boa parte do meu tempo mexendo com back-end: construindo APIs, automatizando tarefas chatas e tentando entender de verdade como as estruturas de dados funcionam por baixo dos panos.

Gosto de aprender fazendo, então quase tudo que estudo acaba virando um projeto aqui no GitHub. Não tenho pressa, tenho constância: um pouco todo dia, sempre tentando escrever um código que eu mesmo consiga entender daqui a seis meses.
